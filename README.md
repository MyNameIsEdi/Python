# מבוא לפייתון - תרגיל ראשון לבודקי תוכנה (QA)

ברוכים הבאים למאגר הקוד (Repository) הראשון שלי! 🚀
הפרויקט הזה נועד לתרגל מושגי בסיס בשפת Python, כצעד ראשון בעולם פיתוח האוטומציה.

## מה הפרויקט כולל?
בקובץ `main.py` ישנו קוד שמתרגל את הנושאים הבאים:
* **הדפסה למסך:** שימוש ב־`print()`.
* **משתנים:** יצירה, השמה ושינוי של ערכים בזמן ריצה.
* **סוגי נתונים בסיסיים:** התנסות עם מחרוזות, מספרים וערכים בוליאניים.
* **קלט ממשתמש:** שימוש ב־`input()` כדי לקבל נתונים דינמיים.
* **משפטי תנאי:** שימוש ב־`if/else` כדי להחליט אם בדיקה עברה (Pass) או נכשלה (Fail).

## סוגי משתנים בסיסיים שנלמדו
| סוג נתון | שם באנגלית | דוגמה בקוד |
| :--- | :--- | :--- |
| מחרוזת טקסט | String | `"Dana"` |
| מספר שלם | Integer | `28` |
| מספר עשרוני | Float | `95.5` |
| בוליאני (אמת/שקר) | Boolean | `True` / `False` |

## דרישות מוקדמות

1. [Python](https://www.python.org/downloads/) מותקן על המחשב.
2. עורך קוד (IDE) כמו [VS Code](https://code.visualstudio.com/) או PyCharm.
